Легенда: `[x]` сделано · `[~]` частично · `[ ]` впереди · **← СЕЙЧАС** — текущий этап.

## Дедлайны

- Ноябрь 2026, точная дата неизвестна — показ коллегам
- 14 дней на разработку MVP

## Стек
- Backend: Python, FastAPI, **psycopg3 (без ORM)**, Alembic
- БД: PostgreSQL 16 + pgvector
- Frontend: React (Vite) + Tailwind + framer-motion + r3f, только Chrome
- ИИ: абстракция `LLMProvider` Protocol (chat / stream_chat / embed / moderate). Реализован `YandexProvider`. Claude и GigaChat — после показа коллегам
- Embeddings: YandexGPT embeddings (text-search-doc / text-search-query), 256d
- RAG: PDF → чанки 400 слов → embeddings → pgvector HNSW cosine → топ-5 с фильтром `source` (`textbook_8_algebra`, `textbook_8_geometry`, `olympiad`)
- Голос: Web Speech API, якоря «ии вопрос» / «ии ответь», ответ текстом. Fallback — видимая кнопка микрофона и live-индикация распознанного текста
- Деплой: VPS (Timeweb или Hetzner), Ubuntu, Docker Compose, Nginx, Let's Encrypt, домен .ru
- Авторизация: учитель — логин/пароль (JWT), ученики — персональный QR-токен (постоянный), страница профиля с прогрессом

## Генерация контента нейронкой
Внутренний сервис `ContentGenerator` с методами `generate_task`, `generate_test`, `generate_weekly_problem`. Схема: учитель в админке жмёт «сгенерировать», выбирает тему/страницы/сложность/источник (textbook или olympiad), бэк берёт релевантные чанки из pgvector, отправляет в выбранную модель с промптом под нужный формат, получает структурированный JSON, валидирует через Pydantic, сохраняет в БД со статусом «черновик». Учитель редактирует и публикует. Опубликованное помечено «проверено учителем», черновики — «сгенерировано ИИ».

## ТЕКУЩИЙ ЭТАП: деплой на VPS

Цель — сайт в интернете по своему домену за HTTPS, прод-доступен из класса.

Задачи:
1. Выбрать и купить VPS (Timeweb или Hetzner), Ubuntu 22.04/24.04
2. Купить домен `.ru`, настроить A-запись
3. Dockerfile для backend (uvicorn + alembic upgrade в entrypoint)
4. Dockerfile для frontend (vite build → nginx:alpine с готовой статикой)
5. `docker-compose.prod.yml`: postgres (pgvector), backend, nginx
6. Nginx reverse-proxy: `/` → frontend статика, `/api/*` → backend
7. Let's Encrypt (certbot) с автообновлением
8. `.env.prod` на сервере, секреты не в git
9. Скрипт деплоя (git pull → docker compose build → up -d → migrate)
10. pg_dump в cron, бэкапы на объектное хранилище или вторую машину

## Риски
- Галлюцинации нейронки в задачах — защита через обязательную ручную проверку перед публикацией
- Качество олимпиадных задач от нейронки — брать из загруженного сборника, не выдумывать с нуля
- Структурированный вывод JSON — валидация через Pydantic, повторный запрос при ошибке
- Утечка `.env` с ключами YandexGPT — секреты только на сервере, не в git, не в Docker image
