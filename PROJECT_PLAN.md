# Сайт учителя математики — план проекта

## Дедлайны
- 19.11.2026 — первые тесты с классом, деплой того что успеем
- Ноябрь 2026, точная дата неизвестна — показ коллегам
- 14 дней на разработку MVP

## Стек
- Backend: Python, FastAPI, SQLAlchemy, Alembic
- БД: PostgreSQL + pgvector
- Frontend: React (Vite) + Tailwind, только Chrome
- ИИ: абстракция провайдеров LLMProvider. К 19.11 реализуем только YandexGPT (бесплатная квота, работает из РФ). Claude и GigaChat — после показа коллегам
- Embeddings: YandexGPT embeddings (text-search-doc / text-search-query)
- RAG: PDF → чанки 500 слов → embeddings → pgvector → поиск топ-5 → в промпт. У чанков поле source_type: textbook_8, textbook_9, textbook_11, olympiad. При поиске фильтр по классу и типу источника
- Голос: Web Speech API, якоря "ии вопрос" и "ии ответь", ответ текстом. Обязательно fallback — видимая кнопка микрофона и live-индикация распознанного текста
- Деплой: VPS (Timeweb или Hetzner), Ubuntu, Docker Compose, Nginx, Let's Encrypt, домен .ru
- Авторизация: учитель — логин/пароль, ученики — персональный QR-токен (постоянный), страница профиля с прогрессом

## Разделы сайта
1. Главная, кратко о сайте
2. ИИ-теоретик, всплывающие подсказки с теорией (общий чат + голос, 8 класс)
3. Задача недели (учитель вручную или нейронка по сборнику олимпиадок — когда заказчик пришлёт сборник)
4. Пропустил урок? ЗАГЛЯНИ (пересказ от нейронки по учебнику 8 класса по теме/дате)
5. Вклад в оценку (задачи и простые тесты для 8 класса, учитель вручную или нейронка по учебнику)
6. Подготовка к ОГЭ (9 класс, если успеем)
7. Подготовка к ЕГЭ (11 класс, если успеем)
8. Математика вокруг нас
9. Наше творчество и достижения
10. Полезные ссылки и видеоразборы
11. Опросы (какую тему повторить, какой формат урока нравится)
12. Админка для учителя
13. Демо-вход учеников через QR

## Генерация контента нейронкой
Внутренний сервис ContentGenerator с методами generate_task, generate_test, generate_weekly_problem. Общая схема: учитель в админке жмёт "сгенерировать", выбирает тему/страницы/сложность/источник (textbook или olympiad), бэк берёт релевантные чанки из pgvector, отправляет в выбранную модель с промптом под нужный формат, получает структурированный JSON, валидирует через Pydantic, сохраняет в БД со статусом "черновик". Учитель редактирует и публикует. Опубликованное помечено "проверено учителем", черновики — "сгенерировано ИИ".

## Договорённости с заказчиком
- Прототип для показа коллегам, потом доработка по итогам
- Учитель — админ, ученики — вход по QR на демо
- Задача недели — олимпиадного уровня, с решением; учитель вручную или нейронка по сборнику
- Вклад в оценку — чередовать задачу с решением и тест; учитель вручную или нейронка по учебнику
- Пропустил урок — через нейронку по учебнику
- Весь ИИ-контент помечается: "сгенерировано ИИ" (черновик) и "проверено учителем" (опубликовано)
- Этапная сдача: сначала этап 1 → показ → обсуждение → этап 2 → этап 3 если успеем

## Риски
- Галлюцинации нейронки в задачах — защита через обязательную ручную проверку перед публикацией
- Качество олимпиадных задач от нейронки — брать из загруженного сборника, не выдумывать с нуля
- Структурированный вывод JSON — валидация через Pydantic, повторный запрос при ошибке
- PDF учебника нужен в первые 2 дня, иначе RAG не успеваем
